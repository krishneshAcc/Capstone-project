Project 11 - Infra Changes with Branching Policy

Objective

Demonstrate infrastructure change management using Git feature branches and Pull Request reviews.

Tasks Performed

Created a dedicated feature branch named feature/project11-branching-policy.

Prepared a separate project directory for infrastructure changes.

Committed project changes to the feature branch.

Pushed the feature branch to GitHub.

Created a Pull Request to merge changes into the main branch.

Reviewed the Pull Request before merging.

Result

Successfully demonstrated a Git branching workflow with Pull Request review and controlled merging into the main branch.
