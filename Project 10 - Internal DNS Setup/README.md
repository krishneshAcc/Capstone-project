Project 10 \- Internal DNS Setup

Objective

Configure internal DNS and access a server using a hostname.

Tasks Performed

- Used the DNS Server role installed with Active Directory.
- Created an A Record named webserver.
- Mapped webserver.capstone.local to IP address 10.5.3.150.
- Verified hostname resolution using the nslookup command.

Result

The hostname successfully resolved to the configured IP address, confirming proper internal DNS configuration.
